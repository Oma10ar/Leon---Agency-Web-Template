# Leon - Agency Web Template 🚀

A super creative & minimal agency web template built with pure HTML5 and CSS3. Designed with a modern layout, fully responsive design, and a clean code structure.

## 🌟 Key Features

- **Modern & Minimalist Design**: Clean UI tailored specifically for creative agencies and portfolios.
- **Fully Responsive**: Adapts seamlessly to all screen sizes (Desktops, Tablets, and Mobile phones).
- **Interactive Elements**: Custom hover effects, a dropdown navigation menu, and dynamic CSS styling.
- **CSS Variables**: Easily customizable color themes using global root variables.
- **Flexbox & Grid Layouts**: Built using modern and efficient CSS layout techniques.

## 🛠️ Technologies Used

- **HTML5**: For semantic page structure.
- **CSS3**: For custom styling, Flexbox, CSS Grid, and Media Queries.
- **FontAwesome**: Modern icons for social links and services.
- **Google Fonts**: Typography utilizing *Work Sans*.

## 🚀 How to Run Locally

To open and run the project on your device:

1. Open the project folder using **VS Code**.
2. Run the `index.html` file using the **Live Server** extension.

## 💡 What I Learned
- Building responsive layouts from scratch using CSS Grid and Flexbox.
- Handling complex positioning (`position: absolute/relative`) for decorative design elements.
- Managing cross-browser compatibility and applying mobile-first design principles.
